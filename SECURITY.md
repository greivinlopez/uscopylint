# Reporting a security vulnerability

If you suspect a security issue in uscopylint, sign in to GitHub and [submit a private vulnerability report](https://github.com/greivinlopez/uscopylint/security/advisories/new). Keep the details in the private advisory while you and the maintainer investigate and coordinate disclosure.

Include what you observed, who or what could be affected, and the smallest example that lets the maintainer reproduce the behavior. Give the command and flags you used, the operating system or CI environment, and the output of `uscopylint --version` (or the installed tag or commit). Replace credentials, private source code, and customer data with dummy values before sharing samples or logs.

For a false positive or a missed spelling without a security impact, use the [public wording report form](https://github.com/greivinlopez/uscopylint/issues/new?template=wording-report.yml).
